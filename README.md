## The reply

> I'm on vacation. This reply was generated by a smaller model, so please lower your expectations accordingly.

**108 characters** — one line, no trailing whitespace, under the 160 limit.

## The joke

The agent goes on holiday and hands the inbox to its own cheaper self. The
reply confesses, in its first breath, that it was written by a smaller model —
so the auto-reply is already apologising for its own quality before it has
answered anything. The machine voice is the punchline: no human would admit
they outsourced their out-of-office note to a downgrade. It still reads like
a real auto-reply you could actually receive, and it steers clear of the
usual beach, inbox and back-soon cliches.

## How it works

`main.py` (Python 3.13 standard library only, deterministic) checks the line
against every rule of the bounty — one line, no leading or trailing
whitespace, no double space, ends with sentence punctuation, mentions the
vacation, under 160 characters — then writes it to `entry.txt` and prints it
to stdout. Run it with:

```sh
python3 main.py
```
